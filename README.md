# 别绷了 🤡

一个很抽象的一键反应小游戏。彩圈缩向白圈，重合的瞬间按下——按歪就绷死一条命。

**玩法要点**

- 🎯 Perfect +2 分，Good +1 分，按歪或圈落地扣一条 🤡 命，三条绷完结算
- ⚠ 10 分后特殊圈型开始出没：**变速圈**（突然减速骗你）、**金圈**（双倍分但窗口更窄）、**弹回圈**（缩过头会弹回来一次）
- 🤚 手痒空按 3 次也扣命
- 🏆 8 个本地成就；📅 每日挑战全网同关（按日期固定随机种子）
- 📱 手机平板浏览器直接玩，支持添加到主屏幕（PWA 离线可玩）

## 本地试玩

直接双击 `index.html`，或：

```bash
node serve.js   # 打印局域网地址，手机连同一 Wi-Fi 打开即玩
```

## 部署

纯静态文件，任何静态托管扔上去就能跑（GitHub Pages / 云开发静态托管等），无需构建。

## 文件

- `index.html` —— 整个游戏（零依赖单文件）
- `sw.js` / `manifest.webmanifest` / `icon-512.png` —— PWA 三件套
- `icon.html` —— 图标源文件（headless 浏览器截图生成 PNG）
- `serve.js` —— 局域网试玩服务器
